SGI SOFTWARE GUILD — SITAMS WEBSITE

FILES
- index.html: Home page
- about.html: About the guild
- departments.html: Departments and responsibilities
- team.html: Directory of all 36 members
- profiles.html: Individual member profiles (one profile shown at a time)
- contact.html: Contact page template
- style.css: Shared responsive design
- images/: Add your real logo and member photos here

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the extracted sgi-software-guild-sitams folder in VS Code.
3. Install the Live Server extension if you do not have it.
4. Right-click index.html and choose Open with Live Server.
5. Navigate using the website menu.

PROFILE BEHAVIOUR
Each team member links to profiles.html#member-id. CSS :target displays only the matching profile. The profile page directory and banner hide while a profile is selected. This works in modern Chrome and Edge and uses HTML + CSS only (no JavaScript).

IMPORTANT CUSTOMIZATION
- Replace sample labels such as “Frontend Member 01” with actual member names.
- Replace avatar initials with actual photos if you have permission. Store photos in images/ and edit each member card/profile markup.
- Add your approved logo and official contact details.
- Contact form is only a front-end template; connect it to a backend/form service before expecting messages to be delivered.
- Current member totals: CEO 1, HR 1, Manager 1, Frontend 11, Backend 16, Database/Data Integrity 6 = 36.

TECHNOLOGY
HTML5 + CSS3 only. No JavaScript or frameworks. Google Fonts are imported online; the site falls back to common system fonts if unavailable.
